# License Options for Jira Step Recorder

## Recommended: MIT License ✅

**Why MIT?**
- ✅ Most popular and widely recognized
- ✅ Very permissive - allows commercial use
- ✅ Simple and easy to understand
- ✅ Compatible with Chrome Web Store
- ✅ Allows others to use, modify, and distribute
- ✅ No requirement to open-source derivative works

**Best for:** Open source projects that want maximum adoption and compatibility.

---

## Alternative License Options

### 1. Apache License 2.0
**Similar to MIT but includes:**
- ✅ Patent protection clause
- ✅ Explicit grant of patent rights
- ✅ More detailed terms

**Best for:** Projects where patent protection is important.

### 2. BSD 3-Clause License
**Very similar to MIT:**
- ✅ Permissive like MIT
- ✅ Includes "no endorsement" clause
- ✅ Slightly more restrictive than MIT

**Best for:** Projects that want to prevent endorsement claims.

### 3. GPL v3 (GNU General Public License)
**Copyleft license:**
- ⚠️ Requires derivative works to be open source
- ⚠️ More restrictive
- ✅ Ensures code remains free

**Best for:** Projects that want to ensure all derivatives are open source.

### 4. Unlicense
**Public domain:**
- ✅ No restrictions at all
- ✅ Dedicated to public domain
- ⚠️ Not recognized in all jurisdictions

**Best for:** Projects you want to completely dedicate to the public.

### 5. Proprietary / All Rights Reserved
**No license (default copyright):**
- ⚠️ No one can use your code without permission
- ⚠️ Not open source
- ✅ Full control over usage

**Best for:** Projects you want to keep completely private.

## Recommendation

**Use MIT License** - It's the best choice for your Chrome extension because:

1. **Chrome Web Store Compatible**: MIT is fully compatible with Chrome Web Store policies
2. **Developer Friendly**: Other developers can easily use and contribute
3. **Commercial Use Allowed**: Companies can use it in their products
4. **Widely Recognized**: Most developers understand MIT terms
5. **Simple**: Easy to understand and apply

## How to Add License to GitHub

1. **Create LICENSE file** (already created with MIT License)
2. **In GitHub repository settings:**
   - Go to repository settings
   - Scroll to "Add license" section
   - Select "MIT License" from dropdown
   - GitHub will automatically create/LICENSE file

3. **Or manually:**
   - The LICENSE file is already created in your project
   - Just commit and push it to GitHub
   - GitHub will automatically detect it
