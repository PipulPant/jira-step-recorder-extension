Icon Generator for Chrome Extension

This file helps you create the required icon files. You can:

  1. Use an online icon generator (e.g., favicon-generator.org)
  2. Create simple icons with text "JR" (Jira Recorder) in 16x16, 48x48, and 128x128 sizes
  3. Use any icon creation tool to generate PNG files

Required files:

  • icon16.png (16x16 pixels)
  • icon48.png (48x48 pixels)
  • icon128.png (128x128 pixels)

Note: The extension will work without icons, but Chrome will show a default icon.
